## 실행 결과

Node.js로 JavaScript 구문, 코드 정본, 내부 상대 경로, 보호 파일과 instructor 보존을 확인했다.
실제 widgets.js를 VM에서 로드하고 최소 DOM 하네스에서 생성한 요소의 이벤트 핸들러를 호출하여 기능을 검사했다.
하네스 검증은 브라우저 렌더링·키보드·접근성 검증을 대신하지 않는다.

14개 검사 통과:

1. HTML 코드와 Python 다운로드 파일 문자 단위 일치(CRLF→LF 정규화)
2. 1-1 단독 작성, HTML ID 중복 0개
3. HTML의 로컬 자산·다운로드 경로 실재
4. 보호 파일과 instructor 원문 보존
5. 발표 조각 12개에 각각 제목 지정
6. 초기 두 스위치 아래, 전등 꺼짐, 미관찰 4개
7. 아래/아래 결과 및 어느 한 스위치를 움직이는 전이
8. 아래/위 결과 및 어느 한 스위치를 움직이는 전이
9. 위/아래 결과 및 어느 한 스위치를 움직이는 전이
10. 위/위 결과 및 어느 한 스위치를 움직이는 전이
11. 네 조합의 표, 중복 기록 수 유지
12. 초기화 시 스위치·전등·관찰 기록 복원
13. 확인 문제의 미선택·오답·정답 피드백
14. 위젯 초기화 예외 시 정적 설명 복원

로컬 Node HTTP 서버를 사용해 HTML 1개, CSS 3개, JS 3개, Python 1개(총 8개)의 응답 200 및 파일 바이트 일치를 확인했다.
서버와 하네스는 검증용 임시 파일로 실행했으며 검증 후 정리한다. npm 의존성·외부 런타임 요청을 추가하지 않았다.

## 미실행 환경

- CUA 인앱 브라우저 연결 시도: `Browser is not available: iab`.
- CUA 브라우저 목록: 빈 배열. 연결된 브라우저 없음.
- `py --version`: `No installed Python found!`. Python 실행기 확인 불가.
- 실제 UI 조작, 화면 캡처, 복사 버튼으로 OS/브라우저 클립보드 읽기, 다운로드 클릭, Python 실행은 검증했다고 주장하지 않는다.
