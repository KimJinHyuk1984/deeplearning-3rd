# 두 스위치의 비밀: 계단 조명의 동작을 학습하는 신경망 만들기

고등학생 대상. 기본 15차시와 선택 심화 5개 주제. 차시당 50분과 파이썬 반복문·리스트·함수 선수학습을 작업 가정으로 한다.
입력 2개 → 은닉 뉴런 2개 → 출력 1개의 신경망을 엑셀과 외부 라이브러리 없는 파이썬으로 구현한다. math 등 표준 모듈은 사용할 수 있다.

사용자와 확정한 학습 순서다. 소단원 하나를 작성한 뒤 사용자가 확인하고 다음 소단원 진행을 지시할 때까지 기다린다.
심화는 별도 식별자로 표시하여 기본 15차시 번호를 유지한다.
