# 2-1 제작 및 검증 기록

## 실행 범위

사용자의 다음 소단원 진행 지시와 수정 요청을 반영했다.

- 무엇을 찾는지: 주어진 입력·정답과 찾을 가중치·편향을 구분한다.
- 어떻게 찾는지: 시작값, 예측, 정답 비교, 근거를 가진 수정, 재비교, 기록 순서로 구성한다.
- 신경망 설명이 먼저 필요하다는 후속 요청: 인공 뉴런과 신경망의 정의, 완성할 2–2–1 구조 그림, 예측과 학습의 구분을 앞에 배치했다.

1-1·1-2의 승인받은 본문과 위젯 코드는 유지했다. 2-1 한 소단원만 작성했다. 커밋·푸시·배포는 수행하지 않았다.

## 산출물

- `index.html#lesson-2-1`: 50분 본문과 발표 조각 21개(초기 19개, 사진 도입 보강 2개)
- `assets/js/neuron-lesson.js`: 매개변수 탐색, 기록, 셀 계산, 예측 영역 위젯
- `assets/css/lecture.css`: 새 위젯과 신경망 구조 그림의 토큰 기반 스타일
- `files/lesson-2-1-neuron.py`: 외부 라이브러리 없는 예측 코드, HTML 복사 원문과 일치
- `docs/lesson-2-1-guide.md`: 교사용 목표·시간·예상 결과·지도 사항
- `assets/img/human-pyramidal-neuron.jpg`: 사람 대뇌피질 뉴런의 실제 현미경 사진
- `docs/lesson-2-1-image-sources.md`: 사진·개념 설명의 출처와 이용 조건

기존 `widgets.js`·`cell-sheet.js`와 공통 파일을 수정하지 않았다. 새 스크립트는 기존 위젯 등록 이후 실행되므로, 지연 스크립트 실행 시점에도 새 위젯이 자동으로 초기화되도록 처리했다.

## 수행한 검사

Node.js v22.22.2의 VM과 최소 DOM 하네스로 실제 함수와 이벤트 핸들러를 실행했다. 다음 34개 검사가 통과했다.

## 교육 내용의 경계

- 이번에는 사람이 값을 탐색한다. 코드가 자동으로 학습한다고 표현하지 않는다.
- 네 XOR 조합을 모두 맞히는 한 뉴런의 매개변수는 없으므로 4/4를 수업 성공 기준으로 삼지 않는다.
- 그림 속 은닉층은 완성할 구조의 소개이며 오늘 구현한 예측기에 은닉층이 있다고 표현하지 않는다.
- 네 점의 모양은 관찰 정답, 배경은 모델의 예측이다. 배경 전체를 실제 관찰 데이터로 취급하지 않는다.
- 이번 점수는 네 관찰 조합에 대한 일치 수다. 일반화 평가나 다음 소단원의 미분 가능한 손실과 구분한다.
- 셀 수식 확인은 유한한 사례 검사이며 모든 수식의 의미적 동등성을 증명하지 않는다.

## 미실행 항목

실제 브라우저 화면·발표 순회·넘침·모바일 배치·테마 대비·키보드·OS 클립보드는 확인하지 못했다. 최소 DOM 하네스는 브라우저 렌더링 검사가 아니다. 공통 발표·복사·테마 코드는 그대로 보존했다.

`py --version`은 `No installed Python found!`를 반환했다. Python 정본을 실제 실행하지 못했으므로 본문의 수치는 수식과 JS로 확인한 예상 결과다. 학생용 Python 코드가 실행되었다고 주장하지 않는다.

초기 제작 이후 아래 사진 보강에서 로컬 JPEG 1개를 추가했다. 외부 라이브러리·CDN·웹폰트·런타임 fetch/XHR를 추가하지 않았다. 현재 상태는 2-1 사용자 확인 대기이며, 다음 소단원은 2-2다.

## 2026-09-29 — 실제 사람 뉴런 사진 도입 보강

사용자의 실제 사람 신경망 사진 제안을 반영해, 사람 뉴런의 현미경 사진 → 기능과 수학적 모델 비교 → 인공 신경망의 정의로 도입을 보강했다. 사진 자체는 한 뉴런의 형태를 보여주는 자료로 정확히 구분했다. 인공 신경망은 생물학적 영감을 받은 수학적 모델이라고 설명한다. 도입 8분과 수업 50분을 유지하며 교사용 시간 배분을 갱신했다.

변경 범위: `index.html`의 2-1 도입, 전용 CSS, JPEG 한 장, 교사 운영안·출처·검증·진행 상태 문서. 이번 보강에서는 JS나 Python을 수정하지 않았다.

사진은 로컬 파일을 이미지 보기 도구로 직접 열어 관찰했다. 409×272px 원본에서 세포체와 뻗어나간 돌기를 확인했다. 가공이나 크롭 없이 원본 바이트를 사용하며 출처의 SHA-1과 일치한다. 저작자 Bob Jacobs, 소속, 원본 설명, CC BY-SA 3.0 링크, 변경 없음 표시를 페이지에 싣는다. 개념은 NIH NICHD와 Stanford CS231n 자료를 참고했다.

Node.js 자료 검사 8개가 통과했다.

1. 1-1·1-2 HTML 본문이 보강 직전과 문자 단위로 같음.
2. 보호 파일·기존 JS·사이트 데이터·Python 정본의 SHA-256이 보강 직전과 같음.
3. 저장한 사진 30,927 bytes가 내려받은 원본 및 출처의 SHA-1과 같음.
4. JPEG 실제 치수 409×272와 HTML width/height가 일치하며 alt·lazy 속성이 있음.
5. 발표 마커가 2-1 21개, 전체 50개임.
6. HTML ID 중복이 없고 로컬 src/href 대상 파일이 존재함.
7. 사진 저작자·라이선스·원본 변경 여부·개념 출처가 본문에 있음.
8. 임시 Node HTTP 서버의 하위 경로에서 HTML·사진·CSS 3개가 200 응답이며 파일 바이트와 일치함. JPEG MIME도 일치함.

`node --check assets/js/neuron-lesson.js`와 `git diff --check`를 다시 수행했다. 자료 검사 스크립트·기준 스냅샷·임시 다운로드는 `work-temp/`에서만 사용하고 정리했다. 사진 공개본은 `assets/img/`에 남긴다. 검증용 HTTP 서버는 종료했다.

위의 초기 34개 기능 검사를 이번에 재실행한 것으로 합산하지 않는다. 이번 검사는 정적 자료·원본·HTTP 검사이며 브라우저 렌더링 검사가 아니다. 신규 사진 슬라이드의 실제 발표 화면, 모바일 배치, 테마와 넘침은 미확인이다. 커밋·푸시·다음 소단원 작성은 수행하지 않았다.
