# 1-2 웹 표와 분산형 차트 변경 및 검증

## 변경 범위

사용자의 분산형 차트 만들기 요청에 따라 학생이 축·점의 구분을 직접 선택하고 한 행씩 차트를 완성하도록 변경했다. 1-2의 학습 목표에 맞춰 E2·E3의 켜짐·꺼짐 합계 수식 활동을 제거했다. 수식 작성은 뉴런의 가중합과 이후 순전파·역전파 활동에서 도입할 예정이다. 현재 2-1 이후 수업은 작성하지 않았다.

- 데이터 표 A2:C5와 데이터 복사·붙여넣기는 유지한다.
- `chart-builder`: X·Y·점의 구분 열 선택, 차트 생성, 설정 초기화.
- `dataset-plot`: 선택한 열에 따른 실제 좌표·계열, 한 행씩 표시·전체 표시, 점·행 버튼 선택, 차트 구성 확인.
- target을 축으로 선택하거나 구분을 없애도 해당 설정대로 그리며 교육용 피드백을 제공한다. 두 입력 축을 서로 바꾸는 것은 올바른 산점도로 인정한다.
- 차트는 데이터 수정에 반응한다. 잘못된 관찰 값을 자동으로 보정하지 않는다.
- 겹친 점은 행 버튼으로 따로 선택할 수 있다. 빈칸·0/1 이외 값이 있는 행은 숨기고 입력 확인을 표시한다.
- 그래프와 설명을 두 열로 배치하고, 작은 화면에서는 세로로 배치한다. 좌표 안내선과 짧은 등장 효과를 추가했다. 모션 감소 설정에서는 효과를 끈다.

공통 CSS·JS·디자인 문서와 승인받은 1-1 본문은 유지했다. `assets/js/cell-sheet.js`도 데이터 셀의 기반으로 유지하며 이번 변경에서는 수정하지 않았다. 새 외부 라이브러리나 데이터 요청을 추가하지 않았다.

## 검증 결과

Node.js v22.22.2의 VM과 최소 DOM 하네스로 실제 위젯 생성 함수와 이벤트 핸들러를 실행했다. 다음 29개 검사를 통과했다.

1. 초기 차트가 비어 있고 단계 표시 버튼이 비활성 상태
2. 축·점의 구분 선택 누락 안내
3. 동일 열을 두 축으로 선택할 때 안내
4. 빈 데이터로 차트를 만들지 않음
5. 표 입력만으로 차트 만들기 단계를 건너뛰지 않음
6. 차트 생성 시 첫 행의 점과 선택한 축·범례 표시
7. 미완성 차트에는 남은 행 표시 안내
8. 다음 행 표시 시 점 추가와 해당 행 선택
9. 네 행 완성 확인과 완료된 표시 버튼 비활성화
10. 메뉴의 미적용 선택이 기존 차트를 바꾸지 않음
11. 잘못된 축도 선택대로 그리며 범례·교육 피드백 일치
12. 구분 없는 차트는 좌표를 유지하며 종류 표시 제거
13. 입력 축 교환을 허용하고 개별 행의 좌표도 바뀜
14. target 수정 시 표식·선택 설명 갱신과 이전 채점 해제
15. 차트 구성 확인에서 관찰과 다른 target 감지
16. 빈 행의 점 숨김과 행 버튼의 비활성·현재 접근성 이름
17. 0/1 이외 값의 오류 표시 및 점 숨김
18. 같은 좌표에 겹치는 점 안내
19. 겹친 점을 행 버튼으로 각각 선택 가능
20. 차트 초기화 시 데이터 보존
21. 붙여넣은 행 순서를 좌표·채점·복사에 반영
22. 데이터 초기화 시 차트 점 제거
23. 일부만 입력된 표의 첫 완성 행부터 표시
24. 차트 선택 컨트롤의 고유 ID와 label 연결
25. 1-1 스위치 실험에서 네 조합 기록 회귀
26. 승인받은 1-1 HTML과 두 Python 코드 블록·정본 일치
27. 보호 파일 보존과 합계 수식 활동 제거
28. HTML ID·로컬 자산·앵커 검증, 소단원·발표 마커 수 유지
29. 로컬 HTTP 자산·다운로드 10개 응답 200 및 정본 바이트 일치

`node --check assets/js/widgets.js`와 `git diff --check`도 수행했다. 검증용 HTTP 서버는 검사 후 닫았으며, work-temp의 이번 검사 스크립트는 정리한다.

발표 마커 수는 1-1 12개 + 1-2 17개 = 29개다. 차트 설정과 그래프를 별도 발표 조각으로 나누었다. 기본 50분 배분은 유지하며 표·차트 18분을 입력 6분, 차트 구성 8분, 비교 설명 4분으로 안내한다.

## 검증 범위의 한계와 종료 상태

실제 브라우저 화면, 발표 순회·넘침, 모바일 배치, 테마 대비, 모션 감소 동작, OS 클립보드, Python 실행은 검증하지 않았다. DOM 하네스 검사는 실제 렌더링이나 키보드·클립보드 동작 확인을 대신하지 않는다.

새로고침하면 데이터와 차트 설정이 초기화된다. 본문과 표에서 데이터 복사·화면 기록으로 보관하도록 안내한다. 사용자 확인 대기 상태이며 커밋·푸시·배포는 수행하지 않았다.
