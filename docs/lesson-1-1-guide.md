# 1-1. 두 스위치의 비밀 — 수업 운영안

- 대단원: Ⅰ. 생활 속 문제를 데이터로 표현하기
- 예상 시간: 50분
- 학습 페이지: `index.html#lesson-1-1`
- 준비물: 브라우저, 메모 도구, 입력이 가능한 파이썬 3 실행 환경
- 선수 지식: 기본 입출력, 반복문, 리스트. 코드는 제공하고 이날은 문법 강의보다 관찰에 집중한다.

## 학습 목표

1. 두 스위치의 위치와 전등 상태를 구분한다.
2. 네 조합을 빠짐없이 관찰하고 기록한다.
3. 스위치를 하나 움직일 때 전등 상태가 어떻게 바뀌는지 설명한다.
4. 관찰 기록을 학습하는 신경망을 만든다는 전체 프로젝트 목표를 이해한다.

## 시간 배분

| 활동 | 시간 | 교사 진행 | 학생 활동 |
| --- | --- | --- | --- |
| 문제 만나기 | 5분 | 아래에서 켠 불을 위에서 끄는 상황 제시 | 경험과 해결 아이디어 말하기 |
| 실험 준비 | 5분 | 위치와 상태 용어, 시작 조건 확인 | 조작 전 결과 예상하기 |
| 스위치 실험 | 12분 | 한 번에 하나씩 움직이도록 안내 | 2인 1조로 조작·관찰 역할 교대, 네 조합 기록 |
| 관찰 설명 | 10분 | 공통점에 관한 질문, 설명 후 답안 펼치기 | 규칙을 한 문장으로 작성 |
| 기록 코드 | 10분 | 복사·실행과 입력 위치 안내 | 네 관찰값 입력, 출력과 실험 표 대조 |
| 확인·정리 | 8분 | 확인 문제, 프로젝트 목표와 연결 | 답과 근거 설명, 관찰 기록 제출 |

파이썬 설치·환경 준비는 수업 전에 마친다. 환경 준비에 시간이 드는 경우 관찰 기록을 종이에 작성하고, 코드 실행은 환경이 준비된 뒤 확인한다.

## 예상 관찰과 해설

| 아래층 위치 | 위층 위치 | 전등 상태 |
| --- | --- | --- |
| 아래 | 아래 | 꺼짐 |
| 아래 | 위 | 켜짐 |
| 위 | 아래 | 켜짐 |
| 위 | 위 | 꺼짐 |

이 모형은 두 스위치가 모두 아래쪽일 때 꺼지는 동작으로 정한다. 실제 두 위치 조명 제어는 배선과 위치 표시에 따라 켜짐·꺼짐의 대응이 반대일 수도 있다. 공통 관찰은 어느 한 스위치를 움직여도 전등 상태가 바뀐다는 점이다.

학생 설명 예: “두 스위치의 위치가 서로 다르면 전등이 켜지고, 같으면 꺼진다.”

확인 문제: 아래층 위 / 위층 아래에서 위층만 위로 이동 → 위 / 위가 되어 꺼짐.

## 지도할 때 구분할 점

- ‘위쪽’을 무조건 ON이라고 부르지 않는다. 위치와 결과를 나누어 말한다.
- 실험 화면은 기존 조명의 동작을 재현한 모형이다. 신경망이 이미 학습한 결과라고 설명하지 않는다.
- `lesson-1-1-observation.py`는 입력한 기록을 출력한다. 정답을 계산하거나 자동 채점하지 않는다.
- 스위치 조작만으로 기록이 채워지지 않는다. ‘현재 조합 기록’을 눌러 관찰을 명시적으로 저장한다. 중복 조합은 수를 늘리지 않는다.
- ‘실험 처음으로’와 페이지 새로고침은 관찰 기록을 지운다. 제출할 기록은 별도 메모나 코드 출력으로 남긴다.
- XOR 명칭과 수식, 숫자 인코딩, 가중치와 학습 알고리즘은 뒤 소단원에서 다룬다.
